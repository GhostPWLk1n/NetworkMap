      Подключение к базе данных
      —

      SQLite — файловая база, не сетевой сервер: «подключение» здесь означает просто открыть файл data.db по другому пути — например, сетевой шаре (Samba/NFS), которую отдаёт контейнер в Docker. Для одновременной записи с нескольких компьютеров это ограниченно надёжно — таково свойство самого SQLite, а не этого приложения.
