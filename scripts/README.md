# Сбор сведений о ПК для импорта в NetworkMap

## Что это

`collect-pc-info.ps1` собирает на компьютере пользователя: ОС, железо (CPU,
RAM, диски), сетевой адаптер (IP/MAC), список установленного ПО — и
сохраняет всё это в один JSON-файл. Дальше этот файл (или папка с
несколькими такими файлами с разных ПК) импортируется в NetworkMap:
кнопка **«Импортировать файл»** в карточке устройства (вкладка «Устройства»)
или **«Импортировать папку»** там же — для пакетного импорта сразу
нескольких файлов.

Список ПО собирается из реестра (как в обычной панели управления Windows),
а не через `Win32_Product` — этот способ WMI при опросе перезапускает
проверку каждого установленного пакета и может занять очень долго.

## Запуск на одном ПК локально

Скопируйте `collect-pc-info.ps1` и `collect-pc-info.bat` на компьютер и
запустите `collect-pc-info.bat` **от имени администратора** (правый клик →
«Запуск от имени администратора») — без прав администратора часть полей
(например, серийный номер) может не собраться, но скрипт не упадёт.

Файл `<ИмяПК>_<дата>.json` появится рядом с батником. Перенесите его (или
сразу несколько таких файлов с разных ПК) на сервер/в общую папку и
импортируйте через NetworkMap.

Чтобы сразу сохранять на сетевой диск, а не переносить вручную, укажите
путь первым аргументом:

```
collect-pc-info.bat \\server\share\inventory
```

## Запуск сразу на нескольких ПК удалённо

Если на удалённых машинах включён WinRM (`winrm quickconfig`) и есть права
администратора, можно запустить сбор сразу на списке компьютеров с одной
консоли, без похода к каждому физически:

```powershell
Invoke-Command -ComputerName PC1,PC2,PC3 -FilePath .\collect-pc-info.ps1 `
    -ArgumentList "\\server\share\inventory"
```

Каждая машина сохранит свой файл прямо в указанную сетевую папку — после
этого в NetworkMap останется один раз нажать «Импортировать папку» и
разобрать все файлы сразу.

## Если что-то пошло не так

Скрипт не должен падать даже без прав администратора или при недоступности
части WMI-классов — соответствующие поля в JSON останутся пустыми, и при
импорте программа просто не тронет эти поля устройства. Если скрипт всё же
падает с ошибкой — пришлите текст ошибки, поправим.
